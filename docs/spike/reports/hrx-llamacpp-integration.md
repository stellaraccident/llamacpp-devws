## 2026-04-18: Targeted graph-entry stream synchronization

## 2026-04-18: GDN direct state update proof and decode recovery

- Graph-shape finding: the live Qwen decode graph orders the fused GDN result as `GATED_DELTA_NET, VIEW, VIEW, CPY, VIEW`. The first view is the attention-score prefix; the second view is the state tail copied to recurrent storage. The previous state-update recognizer only accepted the narrower `GATED_DELTA_NET, VIEW, CPY` pattern, so it missed the real model path and left the ordinary tail `CPY` in place.
- Fix shape: the recognizer now scans through metadata/view nodes after GDN to find the full-tail `VIEW -> CPY`, then elides the preservation copy only if graph inspection proves the original GDN state tail is dead except for that matched update. The fallback path still preserves the full GDN result when tests or callers observe the tail.
- Validation: rebuilt `test-backend-hrx`, `test-backend-ops`, and `llama-bench`; `test-backend-hrx` passed; `test-backend-ops test -b HRX0 -o GATED_DELTA_NET` passed (`18/18` supported HRX cases); `git diff --check` passed.

## 2026-04-18: Prefill recovery through submit granularity
